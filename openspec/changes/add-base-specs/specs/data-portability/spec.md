# Spec Delta

## Purpose

Полное владение данными пользователя: экспорт партии в переносимый формат, читаемый без приложения, и автоматическое резервное копирование базы данных.

## ADDED Requirements

### Requirement: Экспорт партии в JSON
Система ДОЛЖНА (SHALL) экспортировать данные партии (замеры, операции, заметки, итоговые характеристики) в переносимый формат JSON, читаемый без приложения.

#### Scenario: Экспорт и чтение вне приложения
- **WHEN** пользователь экспортирует партию в файл JSON и открывает его в текстовом редакторе
- **THEN** данные партии читаются без установленного приложения, включая сырые показания и применённые поправки

### Requirement: Автоматический бэкап базы данных
Система ДОЛЖНА (SHALL) автоматически создавать резервные копии файла базы данных без действия пользователя.

#### Scenario: Автоматическое резервное копирование
- **WHEN** проходит обычный сеанс работы с приложением
- **THEN** система без участия пользователя поддерживает актуальную резервную копию базы данных
