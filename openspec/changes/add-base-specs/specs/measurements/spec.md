# Spec Delta

## Purpose

Быстрый и защищённый от ошибок ввод замеров партии — плотности, температуры, pH — с привязкой к дате, времени и использованному прибору.

## ADDED Requirements

### Requirement: Добавление замеров
Система ДОЛЖНА (SHALL) позволять добавлять в карточку партии замеры плотности, температуры и pH с привязкой к дате и времени.

#### Scenario: Замер pH
- **WHEN** пользователь добавляет замер pH 3,4 с текущими датой и временем
- **THEN** система сохраняет замер в журнале партии с указанными датой и временем

### Requirement: Обязательный прибор при замере плотности
Система ДОЛЖНА (SHALL) требовать при каждом замере плотности указания использованного прибора: рефрактометр с ATC, рефрактометр без ATC, ареометр или иной.

#### Scenario: Замер без прибора отклонён
- **WHEN** пользователь пытается сохранить замер плотности, не выбрав прибор
- **THEN** система не сохраняет замер и указывает на незаполненное поле прибора

### Requirement: Быстрый ввод замера плотности
Система ДОЛЖНА (SHALL) позволять добавить замер плотности не более чем за 3 действия (клика или нажатия) от главного экрана до сохранения.

#### Scenario: Замер за три действия
- **WHEN** пользователь с главного экрана добавляет замер плотности текущей партии
- **THEN** путь от главного экрана до сохранённого замера укладывается в 3 действия

### Requirement: Динамическая форма замера по прибору
Система ДОЛЖНА (SHALL) перестраивать форму замера в зависимости от выбранного прибора: для ареометра — обязательное поле температуры сусла, для рефрактометра — поле ATC и применение WCF.

#### Scenario: Форма для ареометра
- **WHEN** в форме замера выбран ареометр
- **THEN** поле температуры сусла становится обязательным, а поля рефрактометра скрываются

#### Scenario: Форма для рефрактометра
- **WHEN** в форме замера выбран рефрактометр
- **THEN** форма показывает поле ATC и применяет WCF, не требуя обязательной температуры сусла

### Requirement: Мгновенный предпросмотр скорректированного значения
Система ДОЛЖНА (SHALL) отображать рядом с вводимым показанием моментально пересчитанное скорректированное значение до нажатия «Сохранить».

#### Scenario: Предпросмотр до сохранения
- **WHEN** пользователь вводит сырую плотность и параметры замера
- **THEN** рядом с полем ввода сразу видно пересчитанное значение, ещё до сохранения замера

### Requirement: Значения по умолчанию из контекста партии
Система ДОЛЖНА (SHALL) подставлять в поля замера значения по умолчанию: прибор последнего замера, температуру из предыдущего замера, формулу коррекции из настроек.

#### Scenario: Подстановка дефолтов
- **WHEN** пользователь открывает форму нового замера после предыдущего замера ареометром при 18 °C
- **THEN** прибор и температура предзаполнены значениями предыдущего замера, а формула коррекции — значением из настроек

### Requirement: Валидация вводимых значений
Система ДОЛЖНА (SHALL) предотвращать ввод заведомо невозможных значений (плотность вне физического диапазона, будущая дата) с понятным сообщением об ошибке, а не молчаливой блокировкой.

#### Scenario: Невозможная плотность
- **WHEN** пользователь вводит плотность 0,500 SG
- **THEN** система показывает понятное сообщение о недопустимом диапазоне и не сохраняет замер

#### Scenario: Будущая дата
- **WHEN** пользователь указывает дату замера из будущего
- **THEN** система показывает сообщение об ошибке с пояснением причины отклонения

### Requirement: Правка и удаление замеров с историей
Система ДОЛЖНА (SHALL) позволять редактировать и удалять замеры с сохранением истории правок в журнале партии.

#### Scenario: Исправление опечатки
- **WHEN** пользователь исправляет опечатку в плотности сохранённого замера
- **THEN** график перестраивается по новым данным, а журнал сохраняет след правки

### Requirement: Пакетный ввод замеров
Система ДОЛЖНА (SHALL) позволять вносить несколько замеров подряд (например, контрольные точки дня) без повторного открытия формы.

#### Scenario: Контрольные точки дня
- **WHEN** пользователь вводит три замера плотности за один день подряд
- **THEN** после сохранения первого замера форма остаётся открытой и готовой к вводу следующего
