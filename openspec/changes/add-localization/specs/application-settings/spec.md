# Spec Delta

## ADDED Requirements

### Requirement: Настройка языка интерфейса
Экран настроек ДОЛЖЕН (SHALL) содержать выбор языка интерфейса. Выбор ДОЛЖЕН (SHALL) применяться ко всем экранам сразу, без перезапуска приложения, и сохраняться автоматически вместе с остальными настройками.

#### Scenario: Выбор языка в настройках
- **WHEN** пользователь выбирает язык в настройках
- **THEN** выбор применяется ко всем экранам и сохраняется без отдельного действия сохранения

#### Scenario: Возврат к языку системы
- **WHEN** пользователь выбирает «Как в системе»
- **THEN** при следующем запуске язык определяется по языку системы
