# Spec Delta

## MODIFIED Requirements

### Requirement: Единый формат крепости
Система ДОЛЖНА (SHALL) выводить крепость во всех местах интерфейса с единым обозначением единицы. Обозначения единиц вида «% об.» — часть локализации: они ДОЛЖНЫ (SHALL) зависеть от выбранного языка интерфейса — «% об.» на русском, «% ABV» на английском.

#### Scenario: Формат крепости
- **WHEN** крепость отображается в карточке партии, замере или сводке на русском языке
- **THEN** значение сопровождается единицей «% об.» без исключений

#### Scenario: Крепость на английском
- **WHEN** выбран английский язык и крепость отображается в любом месте интерфейса
- **THEN** значение сопровождается обозначением «% ABV» без исключений

#### Scenario: Смена языка не меняет значение
- **WHEN** пользователь переключает язык интерфейса
- **THEN** числовое значение крепости остаётся прежним, а обозначение единицы соответствует новому языку
