# Spec Delta

## ADDED Requirements

### Requirement: Машинные коды сообщений следа
Каждое сообщение следа пересчёта — примечание шага, предупреждение, информационное сообщение — ДОЛЖНО (SHALL) формироваться по машинному коду с параметрами и отображаться на текущем языке интерфейса, независимо от языка, действовавшего при сохранении замера.

#### Scenario: Просмотр после смены языка
- **WHEN** замер сохранён при русском интерфейсе, а затем пользователь переключил язык на английский
- **THEN** примечания шагов, предупреждения и информационные сообщения этого замера отображаются на английском

#### Scenario: Предпросмотр до сохранения
- **WHEN** пользователь вводит показание и видит пересчитанное значение до сохранения
- **THEN** предупреждения и пояснения предпросмотра отображаются на текущем языке интерфейса

### Requirement: Готовый текст следа для экспорта
Вместе с машинными кодами в записи замера ДОЛЖЕН (SHALL) сохраняться готовый текст сообщений следа на языке, действовавшем при сохранении, чтобы данные читались без приложения.

#### Scenario: Чтение экспорта
- **WHEN** партия экспортирована в JSON и открыта в текстовом редакторе
- **THEN** примечания применённых поправок читаются как готовый текст на языке, который был выбран при записи замеров

### Requirement: Записи без машинных кодов
Замеры, сохранённые без машинных кодов сообщений, ДОЛЖНЫ (SHALL) отображать след по сохранённому тексту без ошибок.

#### Scenario: Замер, записанный до появления машинных кодов
- **WHEN** открывается замер, сохранённый без машинных кодов сообщений
- **THEN** его след отображается по сохранённому тексту
