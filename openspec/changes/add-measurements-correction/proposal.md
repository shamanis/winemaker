# Proposal

## Why

Этап 3 — ядро ценности продукта: «точные измерения, честные расчёты». Пользователь ставит партию (этап 2), но пока не может вносить замеры. Этот change даёт полный конвейер замеров — от ввода сырого показания до коррекции по прибору, формуле и температуре — с сохранением полного следа пересчёта.

## What Changes

- Таблицы БД: `measurements` (замеры плотности/температуры/pH с сырым значением, прибором и скорректированным SG) и `measurement_revisions` (аудит правок), миграция drizzle.
- Конвейер коррекции как чистые функции в `shared/calculations/`: температурная коррекция ареометра к 20 °C, калибровочное смещение, WCF + формула Террилла (и линейная альтернатива) для бродящего сусла, инверсия Brix↔SG, персональный WCF из калибровочной пары.
- Калибровка рефрактометра по паре «рефрактометр — ареометр» с записью пары и вычисленного WCF в карточку прибора.
- IPC-каналы замеров + регистрация; настройки `correctionFormula` наконец потребляются конвейером.
- UI: секция замеров в карточке партии с хронологией, быстрый ввод замера (≤3 действия от списка), динамическая форма по прибору, значения по умолчанию из последнего замера, пакетный ввод, правка/удаление с историей, предупреждение об усреднённой коррекции без калибровочной пары.

Изменений spec-уровня нет: реализуются существующие требования `measurements` (9) и `measurement-correction` (8). Change объявлен `skip_specs: true`.

## Capabilities

### New Capabilities

Отсутствуют.

### Modified Capabilities

Отсутствуют — поведение уже специфицировано:

- `measurement-correction`: пересчёт ареометра к 20 °C, калибровочное смещение, WCF, Террилл/линейная по Bi–Bf, калибровочная пара с персональным WCF, полный след пересчёта в записи, только скорректированные значения для расчётов, предупреждение об усреднённой коррекции.
- `measurements`: замеры с датой/временем, обязательный прибор для плотности, ≤3 действия на замер, динамическая форма, мгновенный предпросмотр, дефолты из контекста, валидация, правки с историей, пакетный ввод.

## Impact

- `src/shared/calculations/` — новые чистые функции с юнит-тестами по контрольным точкам (Террилл — дословно из vision).
- `src/main/db/schema.ts` + миграция 0002; `src/main/measurements/` — репозиторий; `src/shared/ipc/contracts.ts` + register/client — каналы.
- `src/renderer` — секция замеров в карточке партии, диалог быстрого ввода, правка с ревизиями.
- Осознанные частичности (design): единый журнал партии с замерами — этап 4 (`batch-journal`); здесь история правок хранится и видна в карточке замера. Температурная коррекция — формула из vision «Корректировка показаний ареометра АС-3» (линейная, с T_кал прибора и предупреждением вне 10–35 °C); замечено расхождение таблицы проверки в vision с формулой в строках 5/15/25 °C — нормативна формула (см. design Risks).
