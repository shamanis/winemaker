# Spec Delta

## Purpose

График динамики плотности сусла по времени, связывающий каждую точку с исходным замером и показывающий «швы» между методами измерения.

## ADDED Requirements

### Requirement: График изменения плотности
Система ДОЛЖНА (SHALL) строить график изменения плотности сусла по времени на основе всех зафиксированных замеров партии.

#### Scenario: Динамика по дням
- **WHEN** у партии есть замеры плотности за несколько дней брожения
- **THEN** график показывает снижение плотности по дням, позволяя оценить скорость и равномерность брожения и вовремя заметить отклонения

### Requirement: Переход от точки графика к замеру
Система ДОЛЖНА (SHALL) позволять открыть карточку замера по клику на точку графика.

#### Scenario: Клик по точке
- **WHEN** пользователь кликает точку графика плотности
- **THEN** открывается карточка соответствующего замера с сырым показанием и применёнными поправками

### Requirement: Различение приборов на графике
Система ДОЛЖНА (SHALL) визуально отличать на графике точки, полученные разными приборами, разными маркерами.

#### Scenario: Смешанные приборы
- **WHEN** партия содержит замеры рефрактометром и ареометром
- **THEN** их точки на графике различаются маркерами, чтобы пользователь видел «швы» между методами измерения
