# Spec Delta

## MODIFIED Requirements

### Requirement: Коррекция рефрактометра после начала брожения
Система ДОЛЖНА (SHALL) корректировать показания рефрактометра после начала брожения по кубической формуле Террилла или упрощённой линейной формуле. Формула Террилла ДОЛЖНА (SHALL) применяться к сырым показаниям рефрактометра (Bi — стартовое, Bf — текущее, без WCF): её регрессия учитывает алкогольное искажение; WCF применяется к стартовому показанию при вычислении OG. Линейная формула (Баллинг) ДОЛЖНА (SHALL) использовать истинный экстракт старта (OE, из OG с WCF) и кажущийся экстракт текущего сусла (AE).

#### Scenario: Кубическая формула Террилла
- **WHEN** выбрана точная формула, старт партии 22 °Bx (сырое) и пользователь вводит текущее показание 14 °Bx (сырое)
- **THEN** система вычисляет плотность в SG ≈ 1.0462 (≈ 11.5 °Bx) по кубической формуле Террилла, не применяя WCF к входам формулы

#### Scenario: Упрощённая линейная формула
- **WHEN** выбрана линейная формула с теми же исходными показаниями
- **THEN** система вычисляет плотность через Баллинг (RE = 0.1808·OE + 0.8192·AE) и результат отличается от Террилла

#### Scenario: Предупреждение об усреднённой коррекции
- **WHEN** у рефрактометра нет калибровочной пары и пользователь вводит показание на бродящем суле
- **THEN** система показывает предупреждение, что коррекция ведётся по усреднённой формуле
