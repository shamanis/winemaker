# Proposal

## Why

Финальный этап MVP: партия уже ставится и измеряется с коррекцией (этапы 1–3), но результаты нельзя увидеть и осмыслить. Этот change закрывает весь скоуп первой версии — расчёты, график, единый журнал, переносимость данных и глоссарий — после чего по плану идёт только полировка перед релизом.

## What Changes

- Чистые функции анализа в `shared/calculations/analysis.ts`: ABV по формуле Hall (дословно из vision), видимая степень сбраживания, остаточный сахар (Баллинг RE → г/л), прогноз завершения брожения **диапазоном** по линейной регрессии динамики плотности.
- Блок «Расчёты» в карточке партии: крепость, сахар, сбраживание, прогноз; пометки о базе расчётов со ссылками на справку; двойное отображение единиц при работе в Brix; крепость везде «% об.».
- График плотности (собственный SVG, без внешних зависимостей): по скорректированным значениям, маркеры по приборам, клик по точке открывает карточку замера, точки фокусируемы с клавиатуры.
- Технологические операции: таблица `batch_operations` (миграция 0003), CRUD, и **единый журнал партии** — таймлайн замеров + операций + переходов статусов в одном месте.
- Экспорт партии в JSON: сборка полного пакета (партия, замеры, ревизии, операции, дрожжи, добавки, история статусов, итог) через диалог сохранения; читается без приложения. Автобэкап БД уже работает со скелета — верифицируется сценарием.
- Экран «Справка»: глоссарий терминов и формулы из vision (Brix→SG, АС-3, Террилл/Баллинг, Hall); термины в интерфейсе — подсказки при наведении.

Изменений spec-уровня нет: реализуются существующие требования `fermentation-calculations` (8), `density-chart` (3), `batch-journal` (3), `data-portability` (2), `glossary` (3). Change объявлен `skip_specs: true`.

## Capabilities

### New Capabilities

Отсутствуют.

### Modified Capabilities

Отсутствуют — поведение уже специфицировано в базовой спеке:

- `fermentation-calculations`: Hall ABV, сахар/сбраживание по скорректированным данным, прогноз-диапазон, приведение к SG, двойные единицы, «% об.», пометка о базе расчётов.
- `density-chart`: график по замерам, переход точка→карточка замера, маркеры приборов.
- `batch-journal`: операции с датой/заметками, единая хронология.
- `data-portability`: экспорт партии в JSON без приложения; автобэкап.
- `glossary`: глоссарий (SG/OG/FG/Brix/ABV/WCF/ATC/pH/T_кал), доступ при наведении/переходом, формулы внутри приложения.

## Impact

- `src/shared/calculations/analysis.ts` — чистые функции с тестами (Hall на контрольном примере из vision-подобных данных, Баллинг RE, регрессия прогноза).
- Миграция 0003 (`batch_operations`); `src/main/journal/` — репозиторий операций; `src/main/export/` — сборка JSON + диалог сохранения (диалог тестируется вручную, сборка — юнит-тестом).
- IPC: каналы операций, экспорта.
- Renderer: внутренние табы карточки партии (Обзор / Замеры+график / Журнал), блок расчётов, SVG-график, экран Справка, компонент подсказок терминов.
- Осознанные частичности (design): прогноз — простая линейная регрессия с честным диапазоном и отказом при нехватке данных; экспорт — формат v1 без импорта (импорт вне скоупа первой версии).
