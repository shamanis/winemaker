# desktop-platform Specification

## Purpose

Полностью локальное кросс-платформенное десктоп-приложение: без сети, аккаунтов и телеметрии, с гарантией сохранности данных при сбоях и сборками под основные платформы.

## Requirements

### Requirement: Полностью локальная работа
Система ДОЛЖНА (SHALL) работать полностью локально: ни один экран и ни одна функция не должны требовать сетевого соединения, аккаунта или облачного сервиса.

#### Scenario: Работа без сети
- **WHEN** компьютер отключён от сети
- **THEN** все функции приложения, включая глоссарий и справку, работают без ограничений

### Requirement: Сохранность данных при сбоях
Система ДОЛЖНА (SHALL) гарантировать, что после сбоя питания, аварийного завершения или обновления приложения журнал партии восстанавливается полностью, включая сырые показания и применённые поправки.

#### Scenario: Восстановление после сбоя питания
- **WHEN** приложение аварийно завершается во время ведения партии и запускается вновь
- **THEN** все сохранённые до сбоя замеры, операции и заметки доступны и не повреждены

### Requirement: Одиночный экземпляр приложения
Система ДОЛЖНА (SHALL) не допускать одновременной работы нескольких экземпляров приложения с одной базой данных.

#### Scenario: Повторный запуск
- **WHEN** пользователь запускает приложение при уже работающем экземпляре
- **THEN** повторный запуск не создаёт второй экземпляр, а активирует уже работающее окно

### Requirement: Кросс-платформенные сборки
Система ДОЛЖНА (SHALL) собираться в CI в бинарные форматы: Windows (.exe), macOS (Intel, Apple Silicon или универсальная сборка), deb для Debian-подобных дистрибутивов, tar.gz для остальных Linux.

#### Scenario: Релизная сборка
- **WHEN** в CI выполняется релизная сборка
- **THEN** на выходе получаются артефакты установщика Windows, приложения macOS и пакетов Linux для всех целевых платформ
