# glossary Specification

## Purpose

Встроенный глоссарий предметной области и справка по формулам, доступные из любого экрана без выхода из приложения, — опора для начинающего винодела.

## Requirements

### Requirement: Встроенный глоссарий
Система ДОЛЖНА (SHALL) содержать встроенный глоссарий предметной области с расшифровкой терминов и сокращений: SG, OG, FG, Brix, ABV, WCF, ATC, pH и других.

#### Scenario: Расшифровка термина
- **WHEN** пользователь открывает глоссарий и находит термин WCF
- **THEN** видит понятную расшифровку поправочного коэффициента сусла без обращения к внешним источникам

### Requirement: Доступ к глоссарию в один клик
Система ДОЛЖНА (SHALL) обеспечивать доступ к глоссарию в один клик из любого места интерфейса, где встречается термин, — подсказкой при наведении или переходом к статье.

#### Scenario: Подсказка при наведении
- **WHEN** пользователь наводит курсор на сокращение OG в любом экране
- **THEN** появляется подсказка с определением или открывается статья глоссария

### Requirement: Справка по формулам внутри приложения
Система ДОЛЖНА (SHALL) позволять просматривать специфику предметной области — формулы пересчёта Brix в SG, коррекции Террилла, расчёта ABV по Hall — без выхода из приложения.

#### Scenario: Просмотр формулы
- **WHEN** пользователь открывает справку из экрана с расчётом
- **THEN** видит применённую формулу и может сверить расчёт вручную
