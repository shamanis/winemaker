# localization Specification

## Purpose
Язык интерфейса приложения: выбор языка в настройках, определение языка по умолчанию и отображение всех пользовательских текстов — экранов, меню и сообщений — на выбранном языке.

## Requirements

### Requirement: Выбор языка интерфейса
Система ДОЛЖНА (SHALL) позволять выбирать в настройках язык интерфейса: «Как в системе», русский или английский. Названия языков в списке ДОЛЖНЫ (SHALL) отображаться на самих этих языках. Явно выбранный язык ДОЛЖЕН (SHALL) сохраняться между запусками приложения и иметь приоритет над языком системы.

#### Scenario: Переключение на английский
- **WHEN** пользователь выбирает в настройках «English»
- **THEN** все тексты интерфейса отображаются на английском

#### Scenario: Выбор сохраняется между запусками
- **WHEN** пользователь выбрал язык и перезапустил приложение на системе с другим языком
- **THEN** интерфейс отображается на выбранном языке

#### Scenario: Возврат к языку системы
- **WHEN** пользователь выбирает «Как в системе»
- **THEN** язык интерфейса определяется по языку системы, как при первом запуске

### Requirement: Язык по умолчанию
Пока пользователь не выбрал язык явно, система ДОЛЖНА (SHALL) определять язык интерфейса по языку операционной системы: русский — для систем с русским языком, английский — для всех остальных.

#### Scenario: Русскоязычная система
- **WHEN** приложение запускается впервые на системе с русским языком
- **THEN** интерфейс отображается на русском

#### Scenario: Система с другим языком
- **WHEN** приложение запускается впервые на системе с любым языком, кроме русского (например, английским или немецким)
- **THEN** интерфейс отображается на английском

### Requirement: Мгновенное переключение языка
Система ДОЛЖНА (SHALL) применять смену языка без перезапуска приложения: все экраны, открытые в момент переключения, перерисовываются на новом языке, а сохранённые данные пользователя остаются неизменными.

#### Scenario: Переключение на открытом экране
- **WHEN** пользователь переключает язык, находясь в карточке партии со списком замеров
- **THEN** заголовки, подписи, подсказки и сообщения отображаются на новом языке, а состав и значения замеров не меняются

### Requirement: Перевод текстов интерфейса
Все пользовательские тексты интерфейса — заголовки, подписи, кнопки, подсказки, пустые состояния, предупреждения, сообщения проверки введённых значений, обозначения единиц, атрибуты доступности — ДОЛЖНЫ (SHALL) отображаться на выбранном языке: русском и английском.

#### Scenario: Английский интерфейс
- **WHEN** выбран английский язык
- **THEN** на всех разделах — партии, справочники, замеры, журнал, график плотности, настройки, справка — тексты отображаются на английском

#### Scenario: Русский интерфейс
- **WHEN** выбран русский язык
- **THEN** на всех разделах тексты отображаются на русском

#### Scenario: Обозначения единиц как локализация
- **WHEN** выбран английский язык
- **THEN** обозначения единиц, зависящие от языка, отображаются принятыми в английском (крепость — «% ABV» вместо «% об.»), а числовые значения не меняются

### Requirement: Сообщения при сохранении данных
Сообщения об ошибках, отказах и результатах проверки введённых значений, которые формируются при сохранении данных, ДОЛЖНЫ (SHALL) отображаться на языке интерфейса независимо от языка системы.

#### Scenario: Показание вне диапазона
- **WHEN** пользователь вводит показание вне физического диапазона и сохраняет замер при английском интерфейсе
- **THEN** сообщение об ошибке отображается на английском и указывает поле и допустимый диапазон

#### Scenario: Операция отклонена
- **WHEN** операция отклоняется, например изменение архивированной партии
- **THEN** сообщение об отказе отображается на языке интерфейса

### Requirement: Нативное меню на языке интерфейса
Нативное меню приложения ДОЛЖНО (SHALL) отображаться на выбранном языке, включая пункты правки, вида и окна. Назначенные пунктам меню горячие клавиши ДОЛЖНЫ (SHALL) сохраняться при смене языка.

#### Scenario: Меню после смены языка
- **WHEN** пользователь переключает язык
- **THEN** меню приложения отображается на новом языке, а горячие клавиши его пунктов работают как раньше

### Requirement: Каталог переводов
Тексты интерфейса ДОЛЖНЫ (SHALL) храниться в каталоге переводов отдельно от кода экранов — по одному набору текстов на язык. Все языки ДОЛЖНЫ (SHALL) содержать одинаковый набор текстов, и каждый используемый текст ДОЛЖЕН (SHALL) присутствовать в каждом языке.

#### Scenario: Расхождение наборов текстов
- **WHEN** в одном из языков отсутствует текст, имеющийся в другом языке, или добавлен лишний
- **THEN** автоматическая проверка завершается ошибкой

#### Scenario: Текст без перевода в коде
- **WHEN** в коде используется текст, отсутствующий в каком-либо языке
- **THEN** автоматическая проверка завершается ошибкой

### Requirement: Добавление нового языка
Для добавления нового языка в приложение ДОЛЖЕН (SHALL) требоваться только каталог этого языка, без изменения кода экранов.

#### Scenario: Новый каталог
- **WHEN** в каталог переводов добавлен новый язык с полным набором текстов
- **THEN** язык становится доступен для выбора в настройках, и весь интерфейс отображается на нём

### Requirement: Резервный язык
Если текст отсутствует в каталоге текущего языка, система ДОЛЖНА (SHALL) показать его на английском, а не служебный идентификатор текста.

#### Scenario: Отсутствующий текст
- **WHEN** текст сообщения отсутствует в каталоге текущего языка
- **THEN** сообщение отображается на английском

### Requirement: Объявление языка интерфейса
Страница интерфейса ДОЛЖНА (SHALL) объявлять текущий язык для вспомогательных технологий и обновлять объявление при смене языка.

#### Scenario: Смена языка
- **WHEN** пользователь переключает язык
- **THEN** объявленный язык страницы соответствует новому языку интерфейса
