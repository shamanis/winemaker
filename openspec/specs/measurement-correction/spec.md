# measurement-correction Specification

## Purpose

Конвейер приборной коррекции: сырые показания ареометра и рефрактометра превращаются в достоверную плотность в SG, а полный след пересчёта сохраняется в записи замера для проверки.

## Requirements

### Requirement: Пересчёт ареометра к стандартной температуре
Система ДОЛЖНА (SHALL) при замере ареометром запрашивать температуру сусла и автоматически пересчитывать показание к стандартной температуре 20 °C.

#### Scenario: Замер при повышенной температуре
- **WHEN** пользователь вводит показание ареометра 1,090 SG при температуре сусла 28 °C
- **THEN** система пересчитывает показание к 20 °C и использует пересчитанное значение как скорректированное

### Requirement: Калибровочное смещение ареометра
Система ДОЛЖНА (SHALL) применять к показаниям ареометра пользовательское калибровочное смещение, заданное в настройках прибора.

#### Scenario: Ареометр завышает
- **WHEN** для выбранного ареометра задано смещение +0,002 SG
- **THEN** каждое показание этого ареометра автоматически исправляется на эту величину до использования в расчётах

### Requirement: Поправочный коэффициент сусла для рефрактометра
Система ДОЛЖНА (SHALL) автоматически применять поправочный коэффициент сусла (WCF) к каждому показанию рефрактометра.

#### Scenario: Применение WCF
- **WHEN** пользователь вводит показание рефрактометра 15 °Bx при WCF прибора 1,04
- **THEN** система применяет WCF к сырому показанию до дальнейших пересчётов

### Requirement: Коррекция рефрактометра после начала брожения
Система ДОЛЖНА (SHALL) корректировать показания рефрактометра после начала брожения по кубической формуле Террилла или упрощённой линейной формуле, используя скорректированные стартовое (Bi) и текущее (Bf) показания в Brix.

#### Scenario: Кубическая формула Террилла
- **WHEN** выбрана точная формула и пользователь вводит текущее показание Bf при известном стартовом Bi
- **THEN** система вычисляет текущую плотность в SG по кубической формуле Террилла

#### Scenario: Упрощённая формула
- **WHEN** выбрана упрощённая линейная формула
- **THEN** текущая плотность вычисляется по линейной формуле от Bi и Bf

### Requirement: Одноразовая калибровка рефрактометра по паре приборов
Система ДОЛЖНА (SHALL) позволять провести одноразовую калибровку: зафиксировать пару «показание рефрактометра — показание ареометра» по одному образцу и вычислить персональный коэффициент коррекции для этого прибора.

#### Scenario: Фиксация калибровочной пары
- **WHEN** пользователь вводит для одного образца сусла показания рефрактометра 21,5 °Bx и ареометра 1,090 SG
- **THEN** система вычисляет персональный коэффициент коррекции и применяет его к последующим показаниям этого прибора вместо усреднённой формулы

### Requirement: Полный след пересчёта в записи замера
Система ДОЛЖНА (SHALL) сохранять в записи каждого замера исходное («сырое») показание, тип прибора, температуру сусла и применённые поправки рядом с итоговым скорректированным значением.

#### Scenario: Проверка пересчёта позже
- **WHEN** пользователь открывает карточку сохранённого замера
- **THEN** в ней видны сырое показание, прибор, температура, применённые поправки и скорректированный итог

### Requirement: Использование только скорректированных значений
Система ДОЛЖНА (SHALL) использовать для всех расчётов и графиков только скорректированные значения плотности, а не сырые показания приборов.

#### Scenario: График по скорректированным данным
- **WHEN** партия содержит замеры и ареометром, и рефрактометром
- **THEN** график и все расчёты строятся по скорректированным значениям этих замеров

### Requirement: Предупреждение о незавершённой калибровке
Система ДОЛЖНА (SHALL) при отсутствии калибровочной пары для рефрактометра предупреждать пользователя, что коррекция ведётся по усреднённой формуле.

#### Scenario: Нет калибровочной пары
- **WHEN** пользователь добавляет замер рефрактометром, для которого не зафиксирована калибровочная пара
- **THEN** система показывает предупреждение об усреднённой коррекции рядом с результатом пересчёта
