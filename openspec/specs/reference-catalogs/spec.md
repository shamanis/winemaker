# reference-catalogs Specification

## Purpose

Пользовательские справочники приборов (с калибровочными параметрами) и штаммов дрожжей, на которые ссылаются партии и замеры; база заполняется самим пользователем, без встроенных каталогов производителя.

## Requirements

### Requirement: Справочник приборов пользователя
Система ДОЛЖНА (SHALL) вести справочник приборов пользователя — рефрактометров и ареометров — с их калибровочными параметрами. Калибровочное смещение ареометра ДОЛЖНО (SHALL) задаваться в °Bx (шкала прибора).

#### Scenario: Ареометр со смещением
- **WHEN** пользователь добавляет ареометр с калибровочным смещением +0.5 °Bx
- **THEN** прибор сохраняется в справочнике, и его смещение применяется в замерах, где он выбран

#### Scenario: Рефрактометр с параметрами
- **WHEN** пользователь добавляет рефрактометр с признаком ATC и WCF 1,04
- **THEN** прибор сохраняется в справочнике с этими параметрами и доступен для выбора в замерах

### Requirement: Справочник штаммов дрожжей
Система ДОЛЖНА (SHALL) вести пользовательский справочник штаммов дрожжей с указанием производителя и характеристик: оптимального температурного диапазона и толерантности к спирту.

#### Scenario: Добавление штамма
- **WHEN** пользователь добавляет штамм с производителем, диапазоном 15–25 °C и толерантностью к спирту 14 % об.
- **THEN** штамм сохраняется в справочнике и доступен для выбора при постановке партии

#### Scenario: Оценка температурного режима
- **WHEN** пользователь фиксирует температуру брожения и сравнивает её с выбранным штаммом
- **THEN** характеристики штамма из справочника доступны в карточке партии для сопоставления

### Requirement: Подсказки при первом добавлении прибора
Система ДОЛЖНА (SHALL) при первом добавлении прибора показывать короткое объяснение, зачем нужны температура сусла или калибровочная пара.

#### Scenario: Первая настройка прибора
- **WHEN** пользователь добавляет первый прибор в справочник
- **THEN** система показывает краткие пояснения о температуре сусла и калибровочной паре, чтобы обязательные поля не пропускались без понимания
